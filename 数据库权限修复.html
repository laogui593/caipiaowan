🔧 数据库权限快速修复

解决 MySQL 用户权限问题

❌ 遇到以下错误？

SELECT command denied to user 'laogui'@'localhost' for table 'think_php'

这是 MySQL 数据库权限问题，需要授予 information_schema 的访问权限。

🔍 运行诊断工具 📖 查看完整指南

步骤 1: 运行诊断工具

点击上方的 "运行诊断工具" 按钮，访问 fix_permissions.php

工具会自动检测：

  • 数据库连接状态
  • 当前用户权限
  • 数据表访问权限
  • 问题原因分析

步骤 2: 以 root 用户执行修复命令

复制以下 SQL 命令，以 MySQL root 用户 身份执行：

-- 1. 删除可能有问题的用户 DROP USER IF EXISTS 'laogui'@'localhost'; -- 2. 重新创建用户 CREATE USER 'laogui'@'localhost' IDENTIFIED BY '123456'; -- 3. 创建数据库 CREATE DATABASE IF NOT EXISTS `laogui` CHARACTER SET utf8 COLLATE utf8_general_ci; -- 4. 授予数据库完整权限 GRANT ALL PRIVILEGES ON `laogui`.* TO 'laogui'@'localhost'; -- 5. 授予 information_schema 的 SELECT 权限（关键！） GRANT SELECT ON `information_schema`.* TO 'laogui'@'localhost'; -- 6. 刷新权限 FLUSH PRIVILEGES; -- 7. 验证权限 SHOW GRANTS FOR 'laogui'@'localhost';

步骤 3: 验证修复结果

再次运行诊断工具，确认所有检查项都显示 ✅

💡 为什么需要 information_schema 权限？

ThinkPHP 框架需要访问 information_schema 数据库来查询表结构、字段信息等元数据。没有这个权限会导致系统无法正常运行。

✅ 修复后应该看到的权限

  • GRANT USAGE ON *.* TO 'laogui'@'localhost'
  • GRANT ALL PRIVILEGES ON `laogui`.* TO 'laogui'@'localhost'
  • GRANT SELECT ON `information_schema`.* TO 'laogui'@'localhost'

🔧 其他修复方法

方法 1: 命令行

mysql -u root -p 然后执行上述 SQL

方法 2: phpMyAdmin

登录后点击 SQL 标签，粘贴命令并执行

方法 3: 宝塔面板

在数据库管理中设置权限，然后在 SQL 终端执行授权命令

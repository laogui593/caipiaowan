问题描述：
  SELECT command denied to user 'laogui'@'localhost' for table 'think_php'

解决方案：
  授予 MySQL 用户对 information_schema 数据库的 SELECT 权限

💡 三种修复方法

  方法1: 命令行（推荐）
    $ mysql -u root -p
    mysql> GRANT SELECT ON `information_schema`.* TO 'laogui'@'localhost';
    mysql> FLUSH PRIVILEGES;

  方法2: phpMyAdmin
    1. 登录 phpMyAdmin
    2. 点击 "SQL" 标签
    3. 粘贴 SQL 命令并执行

  方法3: 宝塔面板
    1. 登录宝塔面板
    2. 进入数据库管理
    3. 执行 SQL 命令

✅ 验证修复

  执行以下命令检查权限：
    mysql> SHOW GRANTS FOR 'laogui'@'localhost';

  应该看到以下输出：
    ✓ GRANT USAGE ON *.* TO 'laogui'@'localhost'
    ✓ GRANT ALL PRIVILEGES ON `laogui`.* TO 'laogui'@'localhost'
    ✓ GRANT SELECT ON `information_schema`.* TO 'laogui'@'localhost'

🔍 常见问题

  Q: 没有 root 权限怎么办？
  A: 联系服务器管理员或主机提供商

  Q: 执行后还是报错？
  A: 1) 确认已执行 FLUSH PRIVILEGES
     2) 重启 Web 服务器
     3) 清除 ThinkPHP 缓存 (Runtime/Cache 和 Runtime/Logs)

  Q: 密码不是 123456？
  A: 修改命令时使用正确的密码，并同步更新 Application/Common/Conf/db.php
